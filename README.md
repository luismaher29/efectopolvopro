# Efecto Polvo PRO

Aplicación complementaria de estudio basada en la guía **Efecto Polvo: Técnica y Maestría**.

## Ejecutar localmente

1. Instala Node.js 22 o superior.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev`.
4. Abre `http://localhost:3000`.

## Publicar

La carpeta está lista para subirse a un repositorio de GitHub e importarse directamente en Vercel. No necesita base de datos ni variables de entorno.

## Acceso

La aplicación solicita una contraseña y guarda el acceso en el navegador del dispositivo.
